팀에서 함께 쓸 수 있는 *Project Coding Harness*를 공유합니다. GPT 기반 *Codex용*과 *Claude Code용*을 함께 준비했습니다.

*하네스가 뭔가요?*
AI가 프로젝트를 읽고 → 규칙에 맞춰 수정하고 → 테스트·검수하고 → 승인한 결정을 기억하도록 돕는 작업 절차와 도구 묶음입니다. 이번 플러그인은 프로젝트 기억, 설정 화면, 검수 기록을 제공합니다.

*왜 필요한가요?*
새 대화마다 프로젝트 구조와 주의사항을 반복 설명하거나, 이전 결정을 놓치고 코드를 고치는 일을 줄이기 위해서입니다. 특히 여러 대화에 걸친 개발, 버그 수정, 리팩터링, 프로젝트 인수인계에 활용할 수 있습니다.

*주요 기능*
• 프로젝트 구조·개발 규칙·검증 방법을 Markdown으로 정리
• 사용자가 승인한 결정만 프로젝트 기억에 저장
• 변경에 맞는 회귀테스트와 적대적 검수 절차 안내
  — 회귀테스트: 수정 때문에 기존 기능이 깨졌는지 확인
  — 적대적 검수: 실패할 입력·경계 상황을 찾아 구현을 반박해보기
• 자동 판단 / 요청할 때만 사용, 검수 깊이·최대 횟수 설정
• 기억과 설정을 각 프로젝트의 `.coding-harness/`에 보관

*설치 방법 — 최초 한 번*
Python 3.10 이상, Git, 사용하는 도구의 CLI(`codex` 또는 `claude`)와 해당 계정 로그인이 필요합니다. 실행 환경에서 `python` 명령이 동작해야 합니다. 별도의 Python 패키지나 하네스 전용 API 키는 필요 없습니다.

PowerShell에 사용하는 도구의 명령 두 줄을 그대로 붙여 넣으면 됩니다. ZIP 다운로드나 수동 파일 복사는 필요 없고, 둘 다 사용하면 둘 다 설치할 수 있습니다.

GPT / Codex용:
```powershell
codex plugin marketplace add ToolStorage/Project-Coding-Harness
codex plugin add project-coding-harness@personal
```

Claude Code용:
```powershell
claude plugin marketplace add ToolStorage/Project-Coding-Harness
claude plugin install project-coding-harness@project-coding-harness-claude --scope user
```

설치 후 Codex/Claude Code를 다시 시작하고, *실제 개발할 프로젝트*에서 새 대화를 시작해주세요. 이후에는 플러그인 경로를 매번 입력할 필요가 없습니다. GPT용 패키지는 Codex에서 사용하는 버전이며, 일반 ChatGPT 웹 대화에 이 명령으로 설치하는 방식은 아닙니다.

*처음 사용할 때 이렇게 요청하세요*
“하네스 설정 페이지를 열어줘.”
“이 프로젝트를 분석하고 기억해줘.”

*개발 중 사용 예시*
“프로젝트 기억과 현재 코드를 확인하고 이 버그를 수정해줘.”
“이번 변경에 회귀테스트와 적대적 검수를 해줘.”
“검수는 최대 3회로 설정해줘.”
“이 프로젝트에서는 하네스를 요청할 때만 사용해줘.”

Claude에서 명시적으로 호출하려면:
`/project-coding-harness:project-coding-harness 하네스 설정 페이지를 열어줘.`

*알아두면 좋은 점*
플러그인을 설치하면 계속 사용할 수 있지만, 모든 요청에서 하네스가 강제로 실행되는 것은 아닙니다. 프로젝트 분석·기억 갱신·적대적 검수는 명시적으로 요청해 주세요. 테스트·검토는 AI가 수행하고 플러그인은 절차와 근거를 관리하므로, 설치 자체가 코드 품질을 보장하지는 않습니다.

프로젝트 기억은 팀에 자동 동기화되지 않습니다. 함께 공유하려면 필요한 `.coding-harness/` 파일을 저장소 등으로 별도 공유해야 합니다.
